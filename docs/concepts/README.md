# Concept Cards / 概念卡片

Concept cards track recurring concepts across aaajiao's works and current practice. They are not definitions to be fixed once and for all. Each card keeps a visible relation between an earlier formulation, source-backed evidence, a current response, and unresolved tensions.

Use a card when a Concept Return draws on more than one work or when a concept changes materially through dialogue. Start from `_template.md`.

## Workflow

1. Retrieve prior works, project documents, and primary interviews.
2. Record only specific, source-backed earlier formulations.
3. Hold a present-tense dialogue with the artist.
4. Add the current response and open tensions to the card.
5. Create a linked dialogue deposit for the session.
6. Promote only durable, tested changes into `skills/aaajiao/SKILL.md`.
